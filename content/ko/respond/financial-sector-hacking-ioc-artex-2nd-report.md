## 금융감독원 전파 IP 19개 — 1보 후속 업데이트

금융감독원 전파 자료로 전달받은 **「금융감독원 전파 의심 IP 목록」**에는 공격자 IP **19개**가 기재돼 있습니다. 침투유형은 **“AI Agent를 활용한 자동화 공격 추정”**으로 설명돼 있습니다.[^fss]

[1보][first]가 ARTEX 공개 소스의 **후보 User-Agent와 도구 식별 흔적**을 다뤘다면, 이번 2보는 **기관 전파 자료의 IP 목록을 추가**하는 업데이트입니다. 공개 소스의 후보 지표와 이번 IP 목록은 구분해 활용합니다.

## 2. 최근 공격과 위협정보 공유 현황

10월 4일 금융당국 설명을 인용한 보도에서는 **신한·KB국민·하나·BNK부산은행, 예가람·웰컴저축은행, 현대캐피탈 등 7개 금융사**의 침해사고에서 공격 IP가 여러 곳에서 겹쳤고, 공격자가 IP를 변경하며 공격한 정황이 확인됐다고 전했습니다.[^incident]

**후속 업데이트도 확인됐습니다.** 10월 7일 뉴시스 보도에 따르면, 금감원·금융보안원은 10월 6일 기준 **총 33개, 중복을 제외하면 28개 IP**를 금융권에 전파했으며, 해당 정보는 **C-TAS에도 공유**됐습니다.[^update]

> **이번 글에 수록한 것은 확보한 PDF의 19개입니다. 후속 보도의 28개 전체 주소는 이 PDF에 없으므로 임의로 보완하지 않았습니다. 실제 운영에는 공식 공유 채널의 최신 목록을 함께 확인해야 합니다.**

## 3. 지금 적용할 대응

다음은 1보의 점검 방향을 이번 IP 목록에 적용한 **운영 권고**입니다.

**① IP를 우선 대응에 반영합니다.** WAF·방화벽·SIEM 등에 개별 IP를 등록해 탐지하고, 정상 서비스 영향과 최신 배포 내용을 확인해 차단 정책을 적용합니다. 원문에 없는 IP 대역까지 임의로 확대하지 않습니다.

**② 접속 여부와 실제 영향을 함께 확인합니다.** WAF·Reverse Proxy·웹서버·API Gateway 로그에서 해당 IP를 대조하고, 탐지된 요청의 **시각·대상 Host·URI·인증·세션·요청 및 응답 내용**을 연결해 조사합니다. 접속 기록이 있다는 것만으로 침해 성공을 확정하지 않습니다. [1보 참고][first]

**③ 목록 갱신과 행위 분석을 병행합니다.** 새로운 IP로 들어오는 반복 조회, 인증·권한과 맞지 않는 접근도 분석합니다. 1보의 User-Agent 후보는 별도 지표로 활용하되, 후보 문자열이 없다는 이유로 조사를 종료하지 않습니다. [1보 참고][first]

**확보된 IOC는 신속히 적용하고, 추가 지표는 계속 갱신해야 합니다. IP 차단은 출발점이며, 실제 침해 여부는 요청·응답과 관련 행위로 확인해야 합니다.**
