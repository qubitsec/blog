# 긴급! 대학 홈페이지 해킹, 당황하지 마세요. 보호해 드리겠습니다.

## 지금 바로 연락 주세요. 지켜 드립니다.

최근 국내 대학을 대상으로 한 해킹과 개인정보 유출 사고가 잇따르고 있습니다.

데일리시큐 보도에 따르면, 인제대학교에서는 수업용 서버 공격으로 개인정보 24,011건이 유출되었으며, 경일대학교에서도 교직원 전용 전자문서시스템 침입 사고가 발생했습니다.

더욱 우려스러운 것은 해킹 포럼에서 국내 대학 31곳의 데이터를 탈취했다는 주장이 제기되었다는 사실입니다.

이제 대학도 더 이상 해킹의 안전지대가 아닙니다.

**우리 학교 홈페이지는 안전합니까?  
해커의 공격을 실시간으로 탐지하고 차단할 준비가 되어 있습니까?**

## 1. 복잡한 구축 없이, DNS 변경만으로 시작하는 대학 웹 보안

대학의 보안 환경을 전면적으로 바꿀 필요는 없습니다.

학교 네트워크에 웹 보안용 VM만 준비해 주십시오.

- **보호 대상:** 학교 메인 홈페이지 및 ESM 웹사이트
- **구축 방식:** 학교 네트워크에 보호용 VM 설치
- **적용 방법:** DNS 변경을 통한 보호 서비스 적용
- **보안 기능:** 웹 공격 실시간 탐지 및 차단

기존 홈페이지와 서비스 운영 환경을 최대한 유지하면서 신속하게 웹 보안 체계를 적용할 수 있습니다.

## 2. 웹셸 공격 대응 – 모든 웹서버에 PLURA-EDR 설치

웹 공격을 차단하는 것만으로는 충분하지 않습니다.

해커가 웹서버에 웹셸(WebShell)을 설치하면 서버를 원격으로 조작하거나 추가 공격의 거점으로 악용할 수 있습니다.

이를 탐지하기 위해서는 실제 웹서버 내부의 행위까지 확인해야 합니다.

**따라서 대학에서 운영하는 모든 웹서버에 PLURA-EDR 에이전트를 설치해야 합니다.**

- **설치 대상:** 학교 내 모든 웹서버
- **주요 목적:** 웹셸 및 악성 파일 관련 행위 탐지
- **탐지 영역:** 프로세스, 파일, 계정 등 서버 행위
- **기대 효과:** 웹서버 내부의 공격 흔적을 확인하고 침해 확산에 대응

웹 보안용 VM은 외부에서 들어오는 웹 공격을 방어하고, PLURA-EDR은 웹서버 내부에서 발생하는 의심 행위를 탐지합니다.

**웹 공격 방어와 웹셸 탐지를 함께 구성해야 합니다.**

## 3. PLURA-XDR – 탐지부터 분석, 대응까지 하나의 플랫폼으로

PLURA-XDR은 웹·서버·PC·계정에서 발생하는 보안 데이터를 연결하여 공격의 흐름을 분석하고 대응하는 통합 보안 플랫폼입니다.

[PLURA-XDR 플랫폼 개요 및 구성](https://www.plura.io/ko/platform_xdr.html)

**PLURA-XDR 통합 보안 구성**

- **WAF:** 웹 요청과 응답을 분석하여 웹 공격 탐지 및 방어
- **EDR:** 서버와 PC의 프로세스·파일·계정 행위 분석
- **SIEM:** 다양한 보안 로그와 이벤트를 연결하여 상관분석
- **SOAR:** 사전에 합의한 정책에 따른 자동 대응
- **Forensic:** 침해 사고의 증거 확보 및 분석

수집된 보안 데이터를 AI로 분석하고, 공격 판단에 필요한 맥락을 연결하여 정책 기반 차단·격리까지 지원합니다.

필요에 따라 PLURA-SOC 전문 보안관제 서비스와 연계할 수도 있습니다.

## 공격을 기다리지 말고, 실시간으로 막아야 합니다.

보안 사고가 발생한 후 대응하는 것만으로는 충분하지 않습니다.

해커의 공격을 실시간으로 탐지하고, 공격 행위를 분석하며, 위협을 차단할 수 있어야 합니다.

우리 대학의 홈페이지와 주요 웹 서비스를 지금부터 보호하십시오.
