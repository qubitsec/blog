# 탐지 후보와 검증 범위

고객 배포용 차단 룰이나 악성 IOC 목록이 아니라 승인 랩에서 얻은 검토 후보다.

|후보|실제 근거|현재 판단|
|---|---|---|
|ARTEX 전용 UA 정확일치|이번 8건은 UA 헤더 자체가 없음|이 조건으로 이번 요청을 식별하지 못함. 오프라인 대조이며 WAF 실행 결과가 아님|
|UA 누락|기준선·케이스 요청 모두에서 관측|AI·공격 고유 표식이 아님. 정상 루트 기준선도 해당|
|SELECT 형태 쿼리 + q 표식 응답|A의 지정 쿼리 요청에서 관측|쿼리 없는 A 대조도 동일 응답이므로 SQL 실행 성공 근거가 아님|
|버전 함수 형태 쿼리 + MariaDB 표식|B의 지정 쿼리 요청에서 관측|쿼리 없는 B 대조도 동일 응답. 실제 DB 버전으로 사용하지 않음|
|5xx 응답|C에서 HTTP 511 관측|합성 케이스의 상태 표식. 장애·침해 증거가 아님|
|스크립트 표식 응답|D에서 텍스트 표식 관측|브라우저 실행 없음. XSS 성공으로 판정하지 않음|
|목록→대조→쿼리 요청 순서|활동 및 요청 시각 연결|지정된 목표의 영향을 받은 행위 후보. AI 고유 패턴 검증 아님|

다음 검증은 WAF의 전체 URI·쿼리·UA·룰 ID·조치와 실행 기록의 대조, 정상 트래픽 오탐 점검이다. 원 서버의 보안 판단에는 별도의 인증·권한·처리 결과 증거가 필요하다. 내부 IP·시험 케이스 경로·라이브러리 식별값을 악성 고객 차단 목록으로 전환하지 않는다.
