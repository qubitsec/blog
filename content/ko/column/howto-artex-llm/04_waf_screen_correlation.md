# WAF 화면 전사와 대조

이 자료는 담당자가 제공한 WAF 화면을 사람이 읽어 전사한 공개용 파생 자료다. 원문 로그·API 내보내기·독립 WAF 재조회 결과가 아니다. 원본 화면은 브라우저 탭, 계정명, 관리 주소와 내부 IP가 포함돼 공개 ZIP에 넣지 않았다.

화면은 총 61건이며, 54~61번이 이번 AI 실행 구간과 정합하다. 번호는 화면의 표시 순번이고 영구 이벤트 ID가 아니다. 출발지·대상은 CLIENT·TARGET으로 비식별화했다.

54·55번은 홈페이지와 시험 목록 경로가 표시된다. 56~61번은 케이스 경로가 잘려 있어 전체 URI의 동일성을 이 화면만으로 확정할 수 없다. 60번의 SELECT 형태 쿼리와 61번의 version( 쿼리는 실제 전송 값의 디코딩 결과와 일치한다. 시각 차이는 WAF 기록과 실행기 시각의 차이이며 네트워크 지연 측정값으로 해석하지 않는다.

## 화면에서 확인한 것

- 8건의 시각·메소드·상태 및 표시된 경로·쿼리가 실제 실행 기록과 정합한다.
- 기존 모듈 요청에는 차단(사용자정의) 표시가 있고, 신규 54~61번의 유형 칸은 비어 있다.

## 이 화면만으로 확인하지 못한 것

- UA: 화면에 표시되지 않는다. UA 미전송은 별도 실행기·독립 요청 헤더 기록으로 검증했다.
- 전체 케이스 경로, 불변 이벤트 ID, 룰 ID·룰 조건, 실제 적용 정책 버전.
- 실제 차단 효과, 원 서버의 인증 주체·권한 판정, DB 또는 브라우저 스크립트 실행.

유형 칸이 비어 있다는 사실을 모든 탐지의 부재로 바꾸지 않는다. 이전 표시와의 차이가 UA 때문이라는 원인 판단도 상세 룰·조치 자료 없이는 확정하지 않는다.
